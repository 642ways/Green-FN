## What does it do

It commits. A lot. Like **40 to 120 times a day**, forever, while you sleep, eat, shower,
or stare at a wall wondering why you became a developer.

Every commit is a deeply meaningful contribution, such as:

```
a3f9c1e  consulted the frog
7b2d04a  optimized nothing by 300%
e91c5f8  pushed to prod on a friday
0d4a7b3  sorry recruiters
c58e2f1  greened it from the logo
91fb6d0  contested? still green
```

## Features

- ✅ **Green.** Your graph. Every square. Dark green.
- ✅ **Time travel.** The `backfill` button paints your **entire past year** green too. Your past self was apparently grinding.
- ✅ **No token needed.** Uses the built-in `GITHUB_TOKEN`. Zero setup brain cells.
- ✅ **Actually counts.** Commits use your own noreply email, so they show up on *your* graph and not some bot's.
- ✅ **Plausible deniability.** Commit messages are plain lowercase, just like a real tired dev.
- ❌ **Useful code.** None. Zero. That's the point.

## Install (takes 60 seconds, recruiters hate this trick)

1. Make a **public** repo called `Green-FN` (not a fork, forks don't count).
2. Push this stuff to `main`.
3. **Settings → Actions → General → Workflow permissions → Read and write permissions** ✅
4. **Actions → Green-FN 🟩 → Run workflow**
   - `grow`: commits right now (default 50, go crazy)
   - `backfill`: makes the last 365 days green 🟩 **← press this one, you know you want to**
5. Refresh your profile. Witness.

## Config (optional)

| What | Where | Default |
|------|-------|---------|
| How often | `cron` in `green.yml` | every 3 hours |
| Commits per run | `5 + RANDOM % 11` | 5–15 |
| Backfill per day | `20 + RANDOM % 21` | 20–40 |
| Your identity | repo variables `GIT_NAME` / `GIT_EMAIL` | your GitHub noreply |
